Primeiros passos

Comece a usá-lo em minutos

Comece com Lixney

1. Baixe e comece

Instale o Lixney e comece a registrar teus movimentos. Os dados são salvos no teu próprio dispositivo.

2. Exporte tua cópia

Nas definições podes exportar teus dados para um arquivo JSON para salvá-los onde quiser.

3. É importante quando precisas

Restaure ou mova teus dados importando o arquivo JSON para a aplicação.

Veja o guia de Lixney

Comece com Lixfly

1. Instale o Lixfly

Baixe o aplicação e crie teu perfil de piloto.

2. Crie teu primeiro plano de voo

Insira origem, destino e altitude para preparar a rota.

3. Consulte o EFB

Revise mapas, listas de verificação e documentação aeronáutica quando precisar deles.

Veja o guia Lixfly
