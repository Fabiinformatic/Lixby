# Security Policy

For the detailed security architecture, safeguards, current gaps, release checklist and incident procedure, see [`docs/security/security.md`](docs/security/security.md).

## Supported Versions

Lixby is under active development, so only the latest version currently receives security updates.

| Version        | Supported          |
| -------------- | ------------------ |
| Latest         | :white_check_mark: |
| Older versions | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Lixby, please report it responsibly.

### 📩 How to Report

* Send an email to: **[info@lixby.es](mailto:info@lixby.es)**
* Or use GitHub's **private vulnerability reporting** if it is enabled for the repository
### 📝 What to Include

To help us respond faster, please include:

* A clear description of the issue
* Steps to reproduce
* Potential impact
* Screenshots or proof of concept

### ⏱️ Response Time

* Initial acknowledgment: **within 24–72 hours**
* Updates: depending on the complexity of the issue

### ✅ Process

* If the vulnerability is confirmed, we will work on a fix as soon as possible
* If it is not valid, we will explain why

### ⚠️ Important

* Please do not disclose vulnerabilities publicly until they are resolved
* Any malicious exploitation may have legal consequences

Thank you for helping keep Lixby secure 🚀
