Getting started

Start using it in minutes

Get started with Lixney

1. Download and start

Install Lixney and start recording your transactions. Data is stored on your own device.

2. Export your backup

From Settings you can export your data to a JSON file to store it wherever you like.

3. Import when you need to

Restore or move your data by importing the JSON file in the app.

View Lixney guide

Get started with Lixfly

1. Install Lixfly

Download the app and create your pilot profile.

2. Create your first flight plan

Enter origin, destination and altitude to prepare the route.

3. Check the EFB

Review maps, checklists and aeronautical documentation whenever you need them.

View Lixfly guide
